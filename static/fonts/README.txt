Family: Inter, variable weight 100 to 900, normal style.
Source: @fontsource-variable/inter 5.3.0 (npm), files/inter-latin-wght-normal.woff2
and files/inter-latin-ext-wght-normal.woff2. No font binaries were modified.
The unicode-range values in fonts.css are copied from that package's wght.css.

Every text style on the site uses Inter: --font-sans and --font-mono in
src/app.css both point to it.
